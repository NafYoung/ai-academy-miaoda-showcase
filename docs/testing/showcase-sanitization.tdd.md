## 目标与范围

当前版本是产品案例页与十张脱敏截图，不是在线课程演示应用。本记录替代早期课程目录演示的验证记录；早期筛选交互、课程数量与覆盖率不再作为当前版本证据。

截图来自原实现前端结构的本机脱敏镜像，使用合成示例数据；不连接组织后台，不公开原实现源码或内部资料。

## 本机检查词的 RED / GREEN 证据

检查旅程：发布者在本机传入需要排除的组织或资料关键词，公开仓库不保存这些词，检查结果只报告文件与规则名。

- RED 检查点：`test: cover local-only privacy review terms`。执行 `node --test tests/privacy-check.test.mjs`，7 项测试中 3 项因尚不支持本机检查词而失败。
- GREEN 检查点：`fix: keep private review terms out of public scripts`。执行 `npm run test:coverage`，10 项全部通过并达到覆盖率门槛。
- 公共测试只使用虚构组织词，不包含实际组织检查词。

## 视觉和图片检查

- 在本机浏览器检查桌面与移动端案例页布局，并保存截图。
- 十张公开图片逐张查看，另执行中英文 OCR 与文本形态检查。
- 网页上线后另行检查页面标题、正文和十张图片的可访问性；不将 HTTP 成功等同于生产业务端到端验证。
- OCR 不能保证发现所有敏感文字，仍需人工检查；图片不因文本扫描跳过二进制而被当作已检查。

## 发布前门禁

每次公开发布前运行：

```bash
npm run test:coverage
npm run privacy:check
npm run screenshots:manifest
npm run screenshots:ocr
git diff --check
```

需要补充本机检查词时，以竖线分隔，通过 `SHOWCASE_PRIVATE_TERMS` 环境变量传入文本及 OCR 检查。检查词不写入仓库、测试夹具或日志。

只有检查通过、图片人工检查完成且公开文件清单确认无误后，才更新公开版本。图片 OCR 依赖本机 Tesseract 及 `chi_sim`、`eng` 语言数据，不属于 Node 单元测试覆盖范围。
