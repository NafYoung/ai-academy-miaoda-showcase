## 浏览器验收

在真实 Chromium 浏览器中验证：

- 桌面端与 390 px 移动端均无横向溢出
- 6 张课程卡片正常渲染
- 搜索、空结果、重置和课程详情交互正常
- 所有外部链接的主机名均为 `www.feishu.cn`
- 控制台错误与页面运行时错误均为 0

## 发布前门禁

每次公开发布前运行：

```bash
npm run test:coverage
npm run privacy:check
git diff --check
```

只有三项均通过，且浏览器检查无回归时，才允许更新公开版本。
