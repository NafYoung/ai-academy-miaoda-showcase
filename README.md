# Orbit Academy — AI 学习平台展示版

这是一个面向求职作品集的公开展示项目，用于呈现 AI 学习平台的信息架构、学习路径和前端交互。项目采用独立、干净的 Git 历史重新搭建，不继承任何原业务系统的代码、配置或提交记录。

**在线预览：** <https://nafyoung.github.io/ai-academy-miaoda-showcase/>

## 展示内容

- 学习总览：将目标、实践与作品证据串成一条可执行路径
- 公开课程目录：6 个飞书官网公开页面，支持搜索、分类筛选与详情查看
- 设计边界：在页面中明确标注数据来源、展示范围和隐私约束
- 响应式体验：适配桌面端与移动端，支持键盘焦点和减少动效偏好

## 隐私边界

本仓库不包含，也不会连接：

- 公司名称、员工、部门、课程记录或学习进度
- 组织身份、租户专属文档、知识库、妙记或附件
- 数据库、多维表格、后台接口、应用标识或访问凭据
- 原项目的提交历史、平台元数据、部署配置或服务端能力文件

课程卡片仅包含标题、原创摘要与 `www.feishu.cn` 官网链接；外部内容版权归原发布方所有。

## 本地查看

无需安装依赖。使用 Node.js 22+ 和 Python 3：

```bash
npm run serve
```

然后打开 <http://localhost:4173>。

## 验证

```bash
npm test
npm run test:coverage
npm run privacy:check
```

隐私检查会阻止环境文件、私有平台元数据、租户资源链接、常见私有标识和凭据形态进入公开版本。
